Token Radar ranks the protocols that still record no token by what their launch would be worth. Each protocol's implied value comes from the snapshot's own figures — its TVL times the median market-cap-to-TVL multiple of the snapshot's live-token protocols in its category, adjusted for seven-day growth and for how long it has run with no token — and each row carries an eight-step farm plan with its cost and time, including the category's main risk and a weekly review. The board covers the full 40-protocol watchlist plus the 160 highest-TVL pre-token protocols below the $50M floor, the dashboard keeps the protocols whose token already trades in a separate live-token view, and a calibration view lists every live-token comp behind each multiple so any multiple can be checked against the snapshot.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts --input <snapshot.json>
```
